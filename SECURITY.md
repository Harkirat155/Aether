# Security Policy

## Supported Versions
Aether is pre-1.0 implementation; security reports are accepted for all current repository content.

## Reporting a Vulnerability
Please report vulnerabilities privately. Do not open public issues for exploitable findings.

Until a dedicated security mailbox is configured, open a private GitHub security advisory if available for this repository.

Include:
- Affected files/areas
- Reproduction steps
- Impact assessment
- Suggested mitigation (if known)

## Response Process
- Acknowledge receipt promptly.
- Triage severity and affected scope.
- Patch and validate with regression coverage.
- Publish coordinated disclosure notes after remediation.

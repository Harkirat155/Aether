# Support

## Where to Ask Questions
- Use GitHub Discussions for design, roadmap, and open-ended questions.
- Open GitHub issues for concrete bugs, documentation gaps, or actionable requests.

## Where to Report Bugs
Use the bug report template and include reproduction details, expected behavior, and observed behavior.

## Collaboration Directly
- Discussions: https://github.com/Harkirat155/Aether/discussions
- Issues: https://github.com/Harkirat155/Aether/issues
- Pull Requests: https://github.com/Harkirat155/Aether/pulls

## Response Expectations
As an early-stage project, response times may vary. Clear and actionable reports are prioritized.
